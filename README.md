# JS Functions Basics Demos

Small vanilla JavaScript exercises covering variables, types, and basic function syntax.

## Features

- **Task 1** — `makeTransaction` computes and formats an order total
- **Task 2** — `getShippingMessage` adds a delivery fee to a price and formats a shipping message
- **Task 3** — `getElementWidth` computes total element width from content, padding, and border (CSS box model)

## Technology

- Vanilla JavaScript

## Running

Open `index.html` in a browser with the developer console open, or run each task script directly with Node:

```
node js/task-01.js
node js/task-02.js
node js/task-03.js
```
